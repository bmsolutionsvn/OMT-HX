# OMT-HX

A second video mode for [Open Media Transport](https://github.com/openmediatransport),
in the way NDI|HX is a second mode of NDI: HEVC from the GPU's hardware encoder
inside ordinary OMT connections. Discovery, audio and tally are OMT's, unchanged.

Shared by BreadCamera (sender) and BreadStudio (receiver).

**Status:** design only. See
[docs/superpowers/specs/2026-10-12-omt-hx-design.md](docs/superpowers/specs/2026-10-12-omt-hx-design.md).
