# OMT-HX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `omthx`, a C++ library that sends and receives video over Open Media Transport in two modes, plain OMT (VMX) and OMT-HX (HEVC from the GPU's hardware encoder), with two command-line tools that measure the link.

**Architecture:** HEVC access units travel as ordinary OMT video frames under the codec tag `HEVC`, through a libomt built from upstream source plus one small patch. `omthx` wraps that libomt: a `Sender` that packs BGRA (with alpha packed under the fill), encodes with the first hardware HEVC encoder that opens, and applies keyframe rules; and a `Receiver` that returns BGRA whichever mode the source uses. Discovery, audio and tally are libomt's, untouched.

**Tech Stack:** C++20, MSVC (Visual Studio 2026), CMake + Ninja, vcpkg (FFmpeg, doctest), .NET 8 SDK (only to build libomt), Windows PowerShell 5.1 scripts. Windows x64 only.

**Spec:** `docs/superpowers/specs/2026-10-12-omt-hx-design.md`

## Global Constraints

- Windows x64 only. MSVC, C++20, `/W4 /permissive- /utf-8 /EHsc`.
- PowerShell scripts must run on Windows PowerShell 5.1: no `&&`, no `?:`, no `??`.
- Pinned upstream: libomtnet `7d29031ff3f355ffa1f0cd08ee24d02e258445dd`, libomt `bb4b67be8e5964f1017592b9fc5406495e704e5d`, release zip v1.0.0.19 with SHA-256 `c62460174499dabe703e3e57372daf5f1dd95f890355d11e30052b9ed35bdac4`.
- Codec tag `HEVC` is the 32-bit value `0x43564548`.
- Video on the wire: HEVC Main, 8-bit 4:2:0, full-range BT.709, progressive, no B-frames, Annex B, parameter sets with every keyframe.
- Encoder order: `hevc_nvenc`, `hevc_amf`, `hevc_qsv`, `hevc_mf`. No software encoder.
- Bits per pixel: Low 0.12, Medium 0.24, High 0.40. Alpha multiplies the bitrate by 1.25.
- Alpha: fill on top, alpha as brightness starting at row `A` = display height rounded up to 16, coded height `2A`. Fill is premultiplied on the wire.
- Keyframes: first frame, receiver request `<OMTHX Keyframe="true" />`, a new libomt drop, an app request, and every 2000 ms. Requested keyframes are at most one per 500 ms.
- Apps use only `include/omthx/omthx.h`. Nothing outside `src/link.cpp` and `tests/libomt_test.cpp` includes `libomt.h`.
- This PC has an AMD Radeon RX 6600 and no NVIDIA GPU. Tests here exercise `hevc_amf`. Never claim `hevc_nvenc` works from a run on this PC.
- `vcpkg.json` lists the same FFmpeg features as BreadCamera on purpose, so vcpkg reuses BreadCamera's cached FFmpeg build instead of compiling FFmpeg again.
- Commit after each task. Nothing is pushed: the repository has no remote, and creating one is the owner's step.

## Review Focus

Inputs the spec implies that are easy to miss. Each has a test in the task named.

1. **A receiver joins while the source is already running.** It must show a picture without waiting for the 2 second keyframe. Task 2 (`KeyframePolicy`), Task 1 (request message reaches the sender), Task 5 (late-join test).
2. **A frame is skipped.** The receiver must freeze, not show a smeared picture, until the next keyframe. Task 2 (`isGap`), Task 5 (`Receiver` waits after a gap).
3. **A picture whose height is not a multiple of 16, such as 1080.** Padding rows must not leak into fill or alpha. Task 3 (pack layout test at 64x40).
4. **Bytes that are not HEVC, or a truncated frame.** The decoder must report an error and recover at the next keyframe, never crash. Task 2 (`isKeyframe` on short input), Task 4 (garbage test).
5. **The picture size changes during a show.** BreadCamera lets the operator change the show format. Task 5 (size-change test).

One case has no test here because this PC cannot produce it: **no hardware HEVC encoder at all.** `Encoder` must throw `std::runtime_error` naming every encoder it tried. Check that by reading `src/encoder.cpp`.

```powershell
# Builds libomt.dll from pinned upstream source plus patches/libomtnet-hx.patch and collects it,
# with libvmx.dll, into third_party/libomt. -Stock skips the patch (used once, to watch the test fail).
# Needs: git, the .NET 8 SDK, Visual Studio with the C++ desktop workload. Windows PowerShell 5.1 or newer.
param([switch]$Stock)
$ErrorActionPreference = 'Stop'
$root = Split-Path $PSScriptRoot -Parent
$work = Join-Path $root 'build\omt-src'
$out = Join-Path $root 'third_party\libomt'
$pins = [ordered]@{
  libomtnet = '7d29031ff3f355ffa1f0cd08ee24d02e258445dd'
  libomt    = 'bb4b67be8e5964f1017592b9fc5406495e704e5d'
}
$zipUrl = 'https://github.com/openmediatransport/libomtnet/releases/download/v1.0.0.19/OpenMediaTransport.Binaries.Release.v1.0.0.19.zip'
$zipSha = 'c62460174499dabe703e3e57372daf5f1dd95f890355d11e30052b9ed35bdac4'

function Check([string]$what) { if ($LASTEXITCODE) { throw "$what failed with exit code $LASTEXITCODE" } }

if (Test-Path $work) { Remove-Item $work -Recurse -Force }
New-Item -ItemType Directory -Force $work, $out | Out-Null

foreach ($name in $pins.Keys) {
  $dir = Join-Path $work $name
  git init -q $dir; Check "git init $name"
  git -C $dir fetch -q --depth 1 "https://github.com/openmediatransport/$name.git" $pins[$name]; Check "git fetch $name"
  git -C $dir -c advice.detachedHead=false checkout -q FETCH_HEAD; Check "git checkout $name"
}

if (-not $Stock) {
  git -C (Join-Path $work 'libomtnet') apply --whitespace=nowarn (Join-Path $root 'patches\libomtnet-hx.patch')
  Check 'applying patches\libomtnet-hx.patch'
}

# Native AOT needs the MSVC linker. .NET 8 does not find Visual Studio 2026 by itself, so use its developer shell.
$vs = & "${env:ProgramFiles(x86)}\Microsoft Visual Studio\Installer\vswhere.exe" -latest -products * -property installationPath
& "$vs\Common7\Tools\Launch-VsDevShell.ps1" -Arch amd64 -HostArch amd64 -SkipAutomaticLocation | Out-Null

dotnet build (Join-Path $work 'libomtnet\libomtnet.csproj') -c Release -f netstandard2.0 -nologo -v q
Check 'dotnet build libomtnet'
dotnet publish (Join-Path $work 'libomt\libomt.sln') -r win-x64 -c Release -p:IlcUseEnvironmentalTools=true -nologo -v q
Check 'dotnet publish libomt'

$zip = Join-Path $work 'omt-release.zip'
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
Invoke-WebRequest -Uri $zipUrl -OutFile $zip -UseBasicParsing
$sha = (Get-FileHash $zip -Algorithm SHA256).Hash.ToLower()
if ($sha -ne $zipSha) { throw "OMT release zip has SHA-256 $sha, expected $zipSha" }
Expand-Archive $zip -DestinationPath (Join-Path $work 'omt-release') -Force

$bin = Join-Path $work 'libomt\bin\Release\net8.0\win-x64'
Copy-Item (Join-Path $bin 'native\libomt.dll'), (Join-Path $bin 'native\libomt.lib'), (Join-Path $bin 'publish\libomt.h') $out -Force
Copy-Item (Join-Path $work 'omt-release\Libraries\Winx64\libvmx.dll') $out -Force
Copy-Item (Join-Path $work 'libomtnet\LICENSE.txt') (Join-Path $out 'LICENSE-OMT.txt') -Force

Get-ChildItem $out | ForEach-Object { '{0,10}  {1}' -f $_.Length, $_.Name }
```

Create `tests/libomt_test.cpp`:

```cpp
// Proves the patch: an HEVC-tagged frame passes through libomt untouched, and plain OMT is unchanged.
#include <doctest/doctest.h>

#include <chrono>
#include <cstring>
#include <vector>

#include <libomt.h>

namespace {
constexpr int kHevc = 0x43564548;
constexpr char kAsk[] = "<OMTHX Keyframe=\"true\" />";
}  // namespace

TEST_CASE("libomt: an HEVC frame passes through and plain OMT still works") {
  omt_send_t* tx = omt_send_create("omthx-test-libomt", OMTQuality_Default);
  REQUIRE(tx != nullptr);
  char address[OMT_MAX_STRING_LENGTH] = {};
  omt_send_getaddress(tx, address, sizeof(address));
  omt_receive_t* rx =
      omt_receive_create(address, static_cast<OMTFrameType>(OMTFrameType_Video | OMTFrameType_Metadata),
                         OMTPreferredVideoFormat_UYVYorBGRA, OMTReceiveFlags_None);
  REQUIRE(rx != nullptr);

  std::vector<uint8_t> payload(1000);
  for (size_t i = 0; i < payload.size(); ++i) payload[i] = static_cast<uint8_t>(i * 7);
  std::vector<uint8_t> uyvy(1280 * 720 * 2, 128);
  const int alphaFlags = OMTVideoFlags_Alpha | OMTVideoFlags_PreMultiplied;

  bool hevc = false, plain = false, asked = false, tally = false;
  int64_t timestamp = 1;
  const auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(10);
  while (std::chrono::steady_clock::now() < deadline && !(hevc && plain && asked && tally)) {
    OMTMediaFrame f = {};
    f.Type = OMTFrameType_Video;
    f.Timestamp = timestamp;
    timestamp += 166667;
    f.Width = 1280;
    f.Height = 720;
    f.FrameRateN = 60;
    f.FrameRateD = 1;
    f.AspectRatio = 16.0f / 9.0f;
    f.ColorSpace = OMTColorSpace_BT709;
    if (!hevc) {
      f.Codec = static_cast<OMTCodec>(kHevc);
      f.Flags = static_cast<OMTVideoFlags>(alphaFlags);
      f.Data = payload.data();
      f.DataLength = static_cast<int>(payload.size());
    } else {
      f.Codec = OMTCodec_UYVY;
      f.Stride = 1280 * 2;
      f.Data = uyvy.data();
      f.DataLength = static_cast<int>(uyvy.size());
    }
    omt_send(tx, &f);

    if (OMTMediaFrame* r = omt_receive(rx, OMTFrameType_Video, 20)) {
      if (static_cast<int>(r->Codec) == kHevc) {
        hevc = r->Data == nullptr && r->CompressedLength == static_cast<int>(payload.size()) &&
               std::memcmp(r->CompressedData, payload.data(), payload.size()) == 0 && r->Width == 1280 &&
               r->Height == 720 && static_cast<int>(r->Flags) == alphaFlags;
        OMTTally program = {0, 1};
        omt_receive_settally(rx, &program);
        OMTMediaFrame m = {};
        m.Type = OMTFrameType_Metadata;
        m.Data = const_cast<char*>(kAsk);
        m.DataLength = sizeof(kAsk);
        omt_receive_send(rx, &m);
      } else if (r->Codec == OMTCodec_UYVY) {
        plain = r->DataLength == 1280 * 720 * 2;
      }
    }
    while (OMTMediaFrame* m = omt_send_receive(tx, 0)) {
      if (m->Data && std::strstr(static_cast<const char*>(m->Data), "<OMTHX Keyframe")) asked = true;
    }
    OMTTally t = {};
    omt_send_gettally(tx, 0, &t);
    if (t.program == 1) tally = true;
  }
  omt_receive_destroy(rx);
  omt_send_destroy(tx);

  CHECK(hevc);   // the patch
  CHECK(plain);  // VMX in, UYVY out, as before
  CHECK(asked);  // a receiver's message reaches the sender
  CHECK(tally);
}
```

Create `include/omthx/omthx.h`:

```cpp
#pragma once
// OMT-HX: one sender and one receiver for plain OMT (VMX) and OMT-HX (HEVC inside OMT).
#include <cstdint>
#include <memory>
#include <span>
#include <string>
#include <vector>

namespace omthx {

enum class Mode { Full, Hx };  // Full = plain OMT with VMX; Hx = HEVC inside OMT
enum class Quality { Low, Medium, High };

struct VideoFormat {
  int width = 0;  // the picture as displayed
  int height = 0;
  int fpsN = 60;
  int fpsD = 1;
  bool alpha = false;
  bool operator==(const VideoFormat&) const = default;
};

struct Tally {
  bool preview = false;
  bool program = false;
  bool operator==(const Tally&) const = default;
};

struct SenderStats {
  std::string encoder;         // "vmx", "hevc_amf", "hevc_nvenc", ...
  uint64_t framesSent = 0;
  uint64_t keyframes = 0;      // Hx only
  uint64_t bytesSent = 0;      // wire bytes, summed over all receivers
  uint64_t framesDropped = 0;  // a receiver was too slow to take a frame
  double lastEncodeMs = 0;     // Hx only: pack and encode of the last frame
  int connections = 0;
};

// One OMT source. sendVideo and sendAudio may run on two threads, but each must stay on its own.
// requestKeyframe, tally and stats are safe from any thread.
class Sender {
 public:
  Sender(const std::string& name, Mode mode, Quality quality);
  ~Sender();
  Sender(const Sender&) = delete;
  Sender& operator=(const Sender&) = delete;

  // bgra: width * height * 4 bytes, top row first. premultiplied says how the colour relates to its alpha.
  // timestamp: OMT units, 10,000,000 per second, one frame duration apart from the previous frame.
  void sendVideo(const VideoFormat& format, std::span<const uint8_t> bgra, bool premultiplied, int64_t timestamp);
  // planar: all samples of channel 0, then all of channel 1, and so on.

#include "codec.h"

#include <cmath>

namespace omthx {

int64_t targetBitrate(const VideoFormat& f, Quality q) {
  static constexpr double kBitsPerPixel[] = {0.12, 0.24, 0.40};
  double bits = kBitsPerPixel[static_cast<int>(q)] * f.width * f.height * f.fpsN / f.fpsD;
  if (f.alpha) bits *= 1.25;
  return std::llround(bits);
}

namespace {
// Calls fn(type) for each NAL unit and stops at the first true.
template <typename F>
bool anyNal(std::span<const uint8_t> d, F fn) {
  for (size_t i = 0; i + 3 < d.size(); ++i) {
    if (d[i] == 0 && d[i + 1] == 0 && d[i + 2] == 1) {
      if (fn((d[i + 3] >> 1) & 0x3F)) return true;
      i += 2;
    }
  }
  return false;
}
}  // namespace

bool hasNalType(std::span<const uint8_t> d, int type) {
  return anyNal(d, [type](int t) { return t == type; });
}

// HEVC types 16 to 23 are the pictures a decoder can start from.
bool isKeyframe(std::span<const uint8_t> d) {
  return anyNal(d, [](int t) { return t >= 16 && t <= 23; });
}

int alphaTop(int height) { return (height + 15) / 16 * 16; }

int codedHeight(const VideoFormat& f) { return f.alpha ? 2 * alphaTop(f.height) : f.height; }

bool isGap(int64_t previous, int64_t current, int fpsN, int fpsD) {
  if (fpsN <= 0 || fpsD <= 0) return false;
  const int64_t frame = 10'000'000LL * fpsD / fpsN;
  const int64_t step = current - previous;
  return step <= 0 || step > frame + frame / 2;
}

bool KeyframePolicy::next(int64_t nowMs, uint64_t dropped, bool requested) {
  if (dropped > dropped_ || requested) pending_ = true;
  dropped_ = dropped;
  const int64_t since = nowMs - lastKeyMs_;
  const bool key = first_ || since >= 2000 || (pending_ && since >= 500);
  if (key) {
    first_ = false;
    pending_ = false;
    lastKeyMs_ = nowMs;
  }
  return key;
}

}  // namespace omthx

SwsContext* makeConverter(int w, int h, AVPixelFormat from, AVPixelFormat to) {
  SwsContext* c = sws_getContext(w, h, from, w, h, to, SWS_BILINEAR, nullptr, nullptr, nullptr);

  const int* bt709 = sws_getCoefficients(SWS_CS_ITU709);
  sws_setColorspaceDetails(c, bt709, 1, bt709, 1, 0, 1 << 16, 1 << 16);  // full range on both sides
  return c;
}

void checkSize(const VideoFormat& f) {
  if (f.width < 2 || f.height < 2 || f.width % 2 || f.height % 2)
    throw std::invalid_argument("width and height must be even and at least 2");
}

uint8_t scale(unsigned colour, unsigned alpha) { return static_cast<uint8_t>((colour * alpha + 127) / 255); }
}  // namespace

Packer::~Packer() {
  sws_freeContext(toNv12_);
  sws_freeContext(toBgra_);
}

void Packer::ensure(int w, int h) {
  if (toNv12_ && w == width_ && h == height_) return;
  sws_freeContext(toNv12_);
  sws_freeContext(toBgra_);
  toNv12_ = toBgra_ = nullptr;
  toNv12_ = makeConverter(w, h, AV_PIX_FMT_BGRA, AV_PIX_FMT_NV12);
  toBgra_ = makeConverter(w, h, AV_PIX_FMT_NV12, AV_PIX_FMT_BGRA);

  height_ = h;

// ponytail: colour conversion and premultiplying run on the CPU, a few ms per 1080p frame.
// Upgrade path: hand the encoder a D3D11 texture and do both in a shader.
void Packer::pack(const VideoFormat& f, std::span<const uint8_t> bgra, bool premultiplied, Nv12& out) {
  checkSize(f);
  const int w = f.width, h = f.height;
  if (bgra.size() != static_cast<size_t>(w) * h * 4)
    throw std::invalid_argument("bgra must be width * height * 4 bytes");
  ensure(w, h);
  const int coded = codedHeight(f);
  out.width = w;
  out.height = coded;
  out.y.resize(static_cast<size_t>(w) * coded);
  out.uv.resize(static_cast<size_t>(w) * coded / 2);

  const uint8_t* src = bgra.data();
  if (f.alpha && !premultiplied) {
    scratch_.resize(bgra.size());
    for (size_t i = 0; i < bgra.size(); i += 4) {
      const unsigned a = bgra[i + 3];
      scratch_[i] = scale(bgra[i], a);
      scratch_[i + 1] = scale(bgra[i + 1], a);
      scratch_[i + 2] = scale(bgra[i + 2], a);
      scratch_[i + 3] = static_cast<uint8_t>(a);
    }
    src = scratch_.data();
  }

  const uint8_t* srcPlanes[4] = {src, nullptr, nullptr, nullptr};
  const int srcStride[4] = {w * 4, 0, 0, 0};
  uint8_t* dstPlanes[4] = {out.y.data(), out.uv.data(), nullptr, nullptr};
  const int dstStride[4] = {w, w, 0, 0};
  sws_scale(toNv12_, srcPlanes, srcStride, 0, h, dstPlanes, dstStride);
  if (!f.alpha) return;

  const size_t row = static_cast<size_t>(w);
  const int top = alphaTop(h);
  uint8_t* y = out.y.data();
  uint8_t* uv = out.uv.data();
  for (int r = h; r < top; ++r) std::memcpy(y + r * row, y + (h - 1) * row, row);                   // under the fill
  for (int r = h / 2; r < top / 2; ++r) std::memcpy(uv + r * row, uv + (h / 2 - 1) * row, row);
  for (int r = 0; r < h; ++r) {
    uint8_t* dst = y + (top + r) * row;
    const uint8_t* a = src + r * row * 4 + 3;
    for (int x = 0; x < w; ++x) dst[x] = a[static_cast<size_t>(x) * 4];
  }
  for (int r = h; r < top; ++r) std::memcpy(y + (top + r) * row, y + (top + h - 1) * row, row);     // under the alpha
  std::memset(uv + (top / 2) * row, 128, (top / 2) * row);                                           // neutral colour
}

void Packer::unpack(const VideoFormat& f, const Nv12& in, std::vector<uint8_t>& bgra) {
  checkSize(f);
  const int w = f.width, h = f.height;
  const size_t rows = static_cast<size_t>(codedHeight(f));
  if (in.width != w || in.height < codedHeight(f) || in.y.size() < rows * w || in.uv.size() < rows * w / 2)
    throw std::invalid_argument("the picture does not match the frame header");
  ensure(w, h);
  bgra.resize(static_cast<size_t>(w) * h * 4);
  const uint8_t* srcPlanes[4] = {in.y.data(), in.uv.data(), nullptr, nullptr};
  const int srcStride[4] = {w, w, 0, 0};

#pragma once
// A moving test picture with grain, for tests and tools. Straight (not premultiplied) alpha.
#include <algorithm>
#include <cmath>
#include <cstdint>
#include <vector>

inline void drawPattern(std::vector<uint8_t>& bgra, int w, int h, int frame, bool alpha) {
  bgra.resize(static_cast<size_t>(w) * h * 4);
  uint32_t rng = 0x9E3779B9u * static_cast<uint32_t>(frame + 1);
  const int cx = w / 2 + static_cast<int>(w / 4 * std::sin(frame * 0.05));
  const int cy = h / 2;
  const int radius = h / 3;
  const int box = (frame * 8) % std::max(1, w - 64);
  auto clamp8 = [](int v) { return static_cast<uint8_t>(std::clamp(v, 0, 255)); };
  for (int y = 0; y < h; ++y) {
    uint8_t* row = bgra.data() + static_cast<size_t>(y) * w * 4;
    for (int x = 0; x < w; ++x) {
      rng ^= rng << 13;
      rng ^= rng >> 17;
      rng ^= rng << 5;
      const int grain = static_cast<int>(rng & 15) - 8;
      int b = ((x + frame * 2) * 255 / w) % 256;
      int g = y * 255 / h;
      int r = 128;
      if (x >= box && x < box + 64 && y >= h / 4 && y < h / 4 + 64) b = g = r = 235;
      row[x * 4] = clamp8(b + grain);
      row[x * 4 + 1] = clamp8(g + grain);
      row[x * 4 + 2] = clamp8(r + grain);
      int a = 255;
      if (alpha) {
        const int dx = x - cx, dy = y - cy;
        a = (radius * radius - dx * dx - dy * dy) * 4 / radius + 128;  // soft edge, about 30 pixels wide
      }
      row[x * 4 + 3] = clamp8(a);
    }
  }
}

  std::string tried;

    const AVCodec* codec = avcodec_find_encoder_by_name(name.c_str());
    if (!codec) {
      tried += name + " (not built); ";
      continue;
    }
    AVCodecContext* c = avcodec_alloc_context3(codec);
    c->width = w;
    c->height = h;
    c->time_base = {fpsD, fpsN};
    c->framerate = {fpsN, fpsD};

    c->rc_max_rate = bitrate;

    c->color_range = AVCOL_RANGE_JPEG;
    c->colorspace = AVCOL_SPC_BT709;
    c->color_primaries = AVCOL_PRI_BT709;
    c->color_trc = AVCOL_TRC_BT709;
    c->flags |= AV_CODEC_FLAG_LOW_DELAY;  // no GLOBAL_HEADER: parameter sets travel with every keyframe
    AVDictionary* o = nullptr;
    lowDelayOptions(name, &o);
    const int rc = avcodec_open2(c, codec, &o);
    av_dict_free(&o);
    if (rc < 0) {
      tried += name + " (" + averr(rc) + "); ";
      avcodec_free_context(&c);
      continue;

    ctx_ = c;
    name_ = name;
    break;

  frame_ = av_frame_alloc();
  packet_ = av_packet_alloc();
}

std::vector<Packet> Encoder::encode(const Nv12& pic, bool forceKeyframe) {
  if (pic.width != ctx_->width || pic.height != ctx_->height)
    throw std::invalid_argument("the picture has the wrong size for this encoder");
  // The frame borrows the picture's memory; FFmpeg copies it inside avcodec_send_frame.
  av_frame_unref(frame_);
  frame_->format = AV_PIX_FMT_NV12;
  frame_->width = pic.width;
  frame_->height = pic.height;
  frame_->data[0] = const_cast<uint8_t*>(pic.y.data());
  frame_->linesize[0] = pic.width;
  frame_->data[1] = const_cast<uint8_t*>(pic.uv.data());
  frame_->linesize[1] = pic.width;
  frame_->color_range = AVCOL_RANGE_JPEG;
  frame_->colorspace = AVCOL_SPC_BT709;
  frame_->pts = index_++;
  frame_->pict_type = forceKeyframe ? AV_PICTURE_TYPE_I : AV_PICTURE_TYPE_NONE;

  const int rc = avcodec_send_frame(ctx_, frame_);
  if (rc < 0) throw std::runtime_error("HEVC encode failed: " + averr(rc));
  std::vector<Packet> out;
  while (avcodec_receive_packet(ctx_, packet_) >= 0) {
    Packet p;
    p.data.assign(packet_->data, packet_->data + packet_->size);
    p.keyframe = isKeyframe(p.data);
    // Safety net for an encoder that keeps its parameter sets out of band.
    if (p.keyframe && !hasNalType(p.data, 32) && ctx_->extradata_size > 4 && ctx_->extradata[0] == 0 &&
        ctx_->extradata[1] == 0) {
      p.data.insert(p.data.begin(), ctx_->extradata, ctx_->extradata + ctx_->extradata_size);
    }
    out.push_back(std::move(p));
    av_packet_unref(packet_);
  }
  return out;
}

#include <cstring>

namespace omthx {
namespace {
// Take D3D11 when FFmpeg offers it; otherwise the software format, which FFmpeg lists last.
AVPixelFormat pickFormat(AVCodecContext*, const AVPixelFormat* formats) {
  const AVPixelFormat* p = formats;
  for (; *p != AV_PIX_FMT_NONE; ++p) {
    if (*p == AV_PIX_FMT_D3D11) return *p;
  }
  return *(p - 1);
}

void copyPlane(uint8_t* dst, const uint8_t* src, int srcStride, int bytes, int rows) {
  for (int r = 0; r < rows; ++r) std::memcpy(dst + static_cast<size_t>(r) * bytes, src + static_cast<size_t>(r) * srcStride, bytes);
}
}  // namespace

Decoder::Decoder() {
  const AVCodec* codec = avcodec_find_decoder(AV_CODEC_ID_HEVC);
  if (!codec) throw std::runtime_error("FFmpeg was built without an HEVC decoder");
  ctx_ = avcodec_alloc_context3(codec);
  ctx_->flags |= AV_CODEC_FLAG_LOW_DELAY;
  if (av_hwdevice_ctx_create(&hw_, AV_HWDEVICE_TYPE_D3D11VA, nullptr, nullptr, 0) >= 0) {
    ctx_->hw_device_ctx = av_buffer_ref(hw_);
    ctx_->get_format = pickFormat;
    name_ = "hevc (d3d11va)";
  } else {
    // ponytail: four frame threads keep 1080p60 in real time but add three frames of delay.
    // Hardware decoding is the real path; this is the fallback for a PC without it.
    ctx_->thread_count = 4;
    name_ = "hevc (software)";
  }
  if (avcodec_open2(ctx_, codec, nullptr) < 0) {
    avcodec_free_context(&ctx_);
    av_buffer_unref(&hw_);
    throw std::runtime_error("cannot open the HEVC decoder");
  }
  frame_ = av_frame_alloc();
  sw_ = av_frame_alloc();
  packet_ = av_packet_alloc();
}

Decoder::~Decoder() {
  av_packet_free(&packet_);
  av_frame_free(&sw_);
  av_frame_free(&frame_);
  avcodec_free_context(&ctx_);
  av_buffer_unref(&hw_);
}

// ponytail: the decoded picture is copied to CPU memory. Upgrade path: hand the D3D11 texture to the app.
Decoded Decoder::decode(std::span<const uint8_t> au, int64_t timestamp, Nv12& out, int64_t& outTimestamp) {
  if (au.empty()) return Decoded::Error;
  // The packet borrows the caller's bytes; FFmpeg copies them, with the padding it needs, in send_packet.
  packet_->data = const_cast<uint8_t*>(au.data());
  packet_->size = static_cast<int>(au.size());
  packet_->pts = timestamp;
  int rc = avcodec_send_packet(ctx_, packet_);
  packet_->data = nullptr;
  packet_->size = 0;
  if (rc < 0) {
    avcodec_flush_buffers(ctx_);
    return Decoded::Error;
  }
  rc = avcodec_receive_frame(ctx_, frame_);
  if (rc == AVERROR(EAGAIN)) return Decoded::NeedMore;
  if (rc < 0) {
    avcodec_flush_buffers(ctx_);
    return Decoded::Error;
  }

  const AVFrame* f = frame_;
  if (frame_->format == AV_PIX_FMT_D3D11) {
    av_frame_unref(sw_);
    if (av_hwframe_transfer_data(sw_, frame_, 0) < 0) {
      av_frame_unref(frame_);
      return Decoded::Error;
    }
    f = sw_;
  } else {
    name_ = "hevc (software)";
  }

  const int w = f->width, h = f->height;
  const bool nv12 = f->format == AV_PIX_FMT_NV12;
  const bool planar = f->format == AV_PIX_FMT_YUV420P || f->format == AV_PIX_FMT_YUVJ420P;
  if (w % 2 || h % 2 || !(nv12 || planar)) {  // 10-bit and 4:2:2 are not OMT-HX version 1
    av_frame_unref(frame_);
    av_frame_unref(sw_);
    return Decoded::Error;
  }
  out.width = w;
  out.height = h;
  out.y.resize(static_cast<size_t>(w) * h);
  out.uv.resize(static_cast<size_t>(w) * h / 2);
  copyPlane(out.y.data(), f->data[0], f->linesize[0], w, h);
  if (nv12) {
    copyPlane(out.uv.data(), f->data[1], f->linesize[1], w, h / 2);
  } else {
    for (int r = 0; r < h / 2; ++r) {
      const uint8_t* u = f->data[1] + static_cast<size_t>(r) * f->linesize[1];
      const uint8_t* v = f->data[2] + static_cast<size_t>(r) * f->linesize[2];
      uint8_t* d = out.uv.data() + static_cast<size_t>(r) * w;
      for (int x = 0; x < w / 2; ++x) {
        d[2 * x] = u[x];
        d[2 * x + 1] = v[x];
      }
    }
  }
  outTimestamp = frame_->pts;
  av_frame_unref(frame_);
  av_frame_unref(sw_);
  return Decoded::Picture;
}

void Sender::sendVideo(const VideoFormat& fmt, std::span<const uint8_t> bgra, bool premultiplied, int64_t timestamp) {
  checkBgra(fmt, bgra);
  OMTMediaFrame f = {};
  f.Type = OMTFrameType_Video;
  f.Timestamp = timestamp;
  f.Width = fmt.width;
  f.Height = fmt.height;
  f.FrameRateN = fmt.fpsN;
  f.FrameRateD = fmt.fpsD;
  f.AspectRatio = static_cast<float>(fmt.width) / static_cast<float>(fmt.height);
  f.ColorSpace = OMTColorSpace_BT709;

  if (d_->mode == Mode::Full) {  // libomt encodes VMX itself
    int flags = 0;
    if (fmt.alpha) flags |= OMTVideoFlags_Alpha;
    if (fmt.alpha && premultiplied) flags |= OMTVideoFlags_PreMultiplied;
    f.Flags = static_cast<OMTVideoFlags>(flags);
    f.Codec = OMTCodec_BGRA;
    f.Stride = fmt.width * 4;
    f.Data = const_cast<uint8_t*>(bgra.data());
    f.DataLength = static_cast<int>(bgra.size());
    omt_send(d_->tx, &f);
    std::lock_guard lock(d_->statsMutex);
    ++d_->stats.framesSent;
    return;
  }

  if (!d_->encoder || !(fmt == d_->format)) {
    d_->encoder = std::make_unique<Encoder>(fmt.width, codedHeight(fmt), fmt.fpsN, fmt.fpsD,
                                            targetBitrate(fmt, d_->quality));
    d_->format = fmt;
    d_->policy = KeyframePolicy();
    d_->stamps.clear();
  }

  const auto t0 = Clock::now();
  d_->packer.pack(fmt, bgra, premultiplied, d_->picture);

  bool requested = d_->appKeyframe.exchange(false);
  while (OMTMediaFrame* m = omt_send_receive(d_->tx, 0)) {  // messages from receivers
    if (m->Data && m->DataLength > 0 &&
        std::string_view(static_cast<const char*>(m->Data), static_cast<size_t>(m->DataLength)).find("<OMTHX Keyframe") !=
            std::string_view::npos)
      requested = true;
  }
  OMTStatistics omt = {};
  omt_send_getvideostatistics(d_->tx, &omt);
  const int64_t nowMs = std::chrono::duration_cast<std::chrono::milliseconds>(Clock::now() - d_->start).count();
  const bool key = d_->policy.next(nowMs, static_cast<uint64_t>(omt.FramesDropped), requested);

  d_->stamps.push_back(timestamp);
  std::vector<Packet> packets = d_->encoder->encode(d_->picture, key);
  const double encodeMs = msSince(t0);

  f.Codec = static_cast<OMTCodec>(kCodecHevc);
  f.Flags = static_cast<OMTVideoFlags>(fmt.alpha ? (OMTVideoFlags_Alpha | OMTVideoFlags_PreMultiplied) : 0);
  uint64_t keyframes = 0;
  for (Packet& p : packets) {
    f.Timestamp = d_->stamps.front();
    d_->stamps.pop_front();
    f.Data = p.data.data();
    f.DataLength = static_cast<int>(p.data.size());
    omt_send(d_->tx, &f);
    keyframes += p.keyframe ? 1 : 0;
  }
  std::lock_guard lock(d_->statsMutex);
  d_->stats.encoder = d_->encoder->name();
  d_->stats.framesSent += packets.size();
  d_->stats.keyframes += keyframes;
  d_->stats.lastEncodeMs = encodeMs;
}

struct Receiver::Impl {
  omt_receive_t* rx = nullptr;
  std::unique_ptr<Decoder> decoder;
  Packer packer;
  Nv12 picture;
  bool waiting = true;  // Hx: discard until a keyframe
  bool haveLast = false;
  int64_t lastTimestamp = 0;
  Clock::time_point lastAsk{};
  std::mutex statsMutex;
  ReceiverStats stats;

  // Count a discarded frame and ask the sender for a keyframe, at most once per 500 ms.
  void discard() {
    {
      std::lock_guard lock(statsMutex);
      ++stats.framesDiscarded;
    }
    const auto now = Clock::now();
    if (now - lastAsk < std::chrono::milliseconds(500)) return;
    lastAsk = now;
    OMTMediaFrame m = {};
    m.Type = OMTFrameType_Metadata;
    m.Data = const_cast<char*>(kKeyframeRequest);
    m.DataLength = sizeof(kKeyframeRequest);
    omt_receive_send(rx, &m);
  }
};

bool Receiver::receiveVideo(VideoFrame& out, int timeoutMs) {
  OMTMediaFrame* f = omt_receive(d_->rx, OMTFrameType_Video, timeoutMs);
  if (!f) return false;
  VideoFormat fmt;
  fmt.width = f->Width;
  fmt.height = f->Height;
  fmt.fpsN = f->FrameRateN;
  fmt.fpsD = f->FrameRateD;
  fmt.alpha = (f->Flags & OMTVideoFlags_Alpha) != 0;

  if (static_cast<int>(f->Codec) != kCodecHevc) {
    // Plain OMT: libomt already decoded VMX to BGRA.
    if (f->Codec != OMTCodec_BGRA || !f->Data || fmt.width <= 0 || fmt.height <= 0) return false;
    const size_t rowBytes = static_cast<size_t>(fmt.width) * 4;
    out.bgra.resize(rowBytes * fmt.height);
    for (int r = 0; r < fmt.height; ++r) {
      std::memcpy(out.bgra.data() + r * rowBytes, static_cast<const uint8_t*>(f->Data) + static_cast<size_t>(r) * f->Stride,
                  rowBytes);
    }
    if (!fmt.alpha) {
      for (size_t i = 3; i < out.bgra.size(); i += 4) out.bgra[i] = 255;
    }
    out.format = fmt;
    out.premultiplied = fmt.alpha && (f->Flags & OMTVideoFlags_PreMultiplied) != 0;
    out.timestamp = f->Timestamp;
    std::lock_guard lock(d_->statsMutex);
    d_->stats.mode = Mode::Full;
    d_->stats.decoder = "vmx";
    ++d_->stats.framesReceived;
    return true;
  }

  // OMT-HX: the patched libomt hands the HEVC access unit over untouched.
  if (!f->CompressedData || f->CompressedLength <= 0) return false;
  const std::span<const uint8_t> au(static_cast<const uint8_t*>(f->CompressedData),
                                    static_cast<size_t>(f->CompressedLength));
  if (d_->haveLast && isGap(d_->lastTimestamp, f->Timestamp, fmt.fpsN, fmt.fpsD)) d_->waiting = true;
  d_->lastTimestamp = f->Timestamp;
  d_->haveLast = true;
  if (d_->waiting && !isKeyframe(au)) {
    d_->discard();
    return false;
  }
  if (!d_->decoder) d_->decoder = std::make_unique<Decoder>();

  const auto t0 = Clock::now();
  int64_t timestamp = 0;
  const Decoded result = d_->decoder->decode(au, f->Timestamp, d_->picture, timestamp);
  if (result == Decoded::NeedMore) {  // the decoder took the keyframe and is filling its pipeline
    d_->waiting = false;
    return false;
  }
  bool ok = result == Decoded::Picture;
  if (ok) {
    try {
      d_->packer.unpack(fmt, d_->picture, out.bgra);
    } catch (const std::invalid_argument&) {
      ok = false;  // the picture does not match its header: treat it like a decode error
    }
  }
  if (!ok) {
    d_->waiting = true;
    d_->discard();
    return false;
  }
  d_->waiting = false;
  out.format = fmt;
  out.premultiplied = fmt.alpha;
  out.timestamp = timestamp;
  std::lock_guard lock(d_->statsMutex);
  d_->stats.mode = Mode::Hx;
  d_->stats.decoder = d_->decoder->name();
  d_->stats.lastDecodeMs = msSince(t0);
  ++d_->stats.framesReceived;
  return true;
}

bool Receiver::receiveAudio(AudioFrame& out, int timeoutMs) {
  OMTMediaFrame* f = omt_receive(d_->rx, OMTFrameType_Audio, timeoutMs);
  if (!f || !f->Data || f->Channels <= 0 || f->SamplesPerChannel <= 0) return false;
  out.sampleRate = f->SampleRate;
  out.channels = f->Channels;
  out.samples = f->SamplesPerChannel;

  const float* p = static_cast<const float*>(f->Data);
  out.planar.assign(p, p + static_cast<size_t>(f->Channels) * f->SamplesPerChannel);
  return true;
}

void writeBmp(const std::string& path, const VideoFrame& v) {
  const uint32_t size = static_cast<uint32_t>(v.bgra.size());
  unsigned char h[54] = {'B', 'M'};
  auto put = [&](int at, uint32_t x) { std::memcpy(h + at, &x, 4); };
  put(2, 54 + size);
  put(10, 54);
  put(14, 40);

  put(22, static_cast<uint32_t>(-v.format.height));

  h[28] = 32;
  put(34, size);
  std::ofstream out(path, std::ios::binary);
  out.write(reinterpret_cast<const char*>(h), sizeof(h));

}

      if (i + 1 >= argc) usage();
      return argv[++i];
    };
    if (a == "--list") list = true;
    else if (a == "--source") source = value();
    else if (a == "--seconds") seconds = std::atoi(value().c_str());
    else if (a == "--dump") dump = value();
    else if (a == "--tally") tally = value();
    else usage();
  }

  try {
    if (list) {
      discover();
      std::this_thread::sleep_for(std::chrono::seconds(2));  // discovery needs a moment
      for (const std::string& s : discover()) std::puts(s.c_str());
      return 0;
    }
    if (source.empty()) usage();

    Receiver receiver(source);
    if (!tally.empty()) receiver.setTally(Tally{tally == "preview", tally == "program"});
    using Clock = std::chrono::steady_clock;
    const auto end = Clock::now() + std::chrono::seconds(seconds);
    auto report = Clock::now() + std::chrono::seconds(1);
    ReceiverStats last;
    VideoFrame frame;
    double delaySum = 0, delayMax = 0;
    int delays = 0;
    while (seconds == 0 || Clock::now() < end) {
      if (receiver.receiveVideo(frame, 100)) {
        const int64_t now =
            std::chrono::duration_cast<std::chrono::nanoseconds>(std::chrono::system_clock::now().time_since_epoch())
                .count() / 100;
        const double delay = (now - frame.timestamp) / 10'000.0;  // ms
        delaySum += delay;
        delayMax = std::max(delayMax, delay);
        ++delays;
        if (!dump.empty()) {
          writeBmp(dump, frame);
          std::printf("wrote %s\n", dump.c_str());
          dump.clear();
        }
      }
      if (Clock::now() >= report) {
        report += std::chrono::seconds(1);
        const ReceiverStats s = receiver.stats();
        std::printf("%-4s %-16s %3llu fps  %7.2f Mbps  decode %5.2f ms  discarded %llu  delay avg %6.2f max %6.2f ms  %dx%d%s\n",
                    s.mode == Mode::Hx ? "HX" : "Full", s.decoder.c_str(),
                    static_cast<unsigned long long>(s.framesReceived - last.framesReceived),
                    (s.bytesReceived - last.bytesReceived) * 8 / 1e6, s.lastDecodeMs,
                    static_cast<unsigned long long>(s.framesDiscarded), delays ? delaySum / delays : 0.0, delayMax,
                    frame.format.width, frame.format.height, frame.format.alpha ? " +alpha" : "");
        last = s;
        delaySum = delayMax = 0;
        delays = 0;
      }
    }
  } catch (const std::exception& e) {
    std::fprintf(stderr, "omthx-recv: %s\n", e.what());
    return 1;
  }
  return 0;
}
```

# OMT-HX

A second video mode for [Open Media Transport](https://github.com/openmediatransport), in the way
NDI|HX is a second mode of NDI: HEVC from the GPU's hardware encoder inside ordinary OMT

## Use it from an app

The app's `vcpkg.json` needs FFmpeg with `avcodec`, `swscale`, `nvcodec` and `amf`.

```cmake
set(OMTHX_ROOT "${CMAKE_SOURCE_DIR}/../OMT-HX" CACHE PATH "OMT-HX checkout")
add_subdirectory("${OMTHX_ROOT}" omthx)
target_link_libraries(my_app PRIVATE omthx)
omthx_copy_runtime(my_app)   # puts libomt.dll and libvmx.dll next to the exe
```

```cpp
#include "omthx/omthx.h"

omthx::Sender sender("Camera 1", omthx::Mode::Hx, omthx::Quality::Medium);
sender.sendVideo(format, bgra, /*premultiplied*/ false, timestamp);
bool onAir = sender.tally().program;

omthx::Receiver receiver("CAMERA-PC (Camera 1)");
omthx::VideoFrame frame;
if (receiver.receiveVideo(frame, 100)) { /* frame.bgra, premultiplied when it has alpha */ }
receiver.setTally({.preview = false, .program = true});
```

Timestamps must be one frame duration apart. A larger step tells the receiver a frame was
skipped, and it holds the last picture until the next keyframe.

## Limits of version 1

8-bit 4:2:0 only. Colour conversion runs on the CPU. A program that speaks only stock OMT sees an
OMT-HX source with audio and no picture. See section 13 of the design.
